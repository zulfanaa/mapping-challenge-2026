# Maps from #30DayMapChallenge 2026

These are maps I created during #30DayMapChallenge 2026 in collaboration with Next Generation Cartographers.

The repository contains PNG images of my maps, visualizing different themes with cartographic techniques.

## Maps Included

### Day 11 – Senses: Sound
**Where can Totoro go? Munich edition**

A map of modelled road traffic noise (Lden, in dB) in the Munich area, reimagined as comfort zones for Totoro, the gentle forest spirit from Studio Ghibli's *My Neighbor Totoro*. The noise classes become places where Totoro can nap, visit, needs to hide, or can't go at all.

The noise levels are symbolised in a watercolor-like style to show that noise does not stop at hard class boundaries, unlike in a general noise map. A dotted layer marks places with two possibilities: modelled noise says Totoro should hide there, but local knowledge suggests these areas (such as parks) are often quieter in real life, so he might still nap or call them home.

- **Data:** [noise data source], Munich area
- **Tool:** ArcGIS Pro
- **Note:** Noise levels are modelled estimates, not measurements.
